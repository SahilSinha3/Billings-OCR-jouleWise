Step 1 User Action
User Drops Bill into Dropzone
Next.js triggers loading shield, locks screen, and creates multipart FormData.
frontend/app/page.tsx ➔ handleFileUpload()
⬇️
Step 2 < 1ms
FastAPI Receives Stream & Hashes SHA-256
Reads raw byte stream in memory and generates SHA-256 fingerprint without touching disk.
backend/app/api/v1/endpoints/bills.py ➔ upload_bill()
⬇️
Step 3 < 5ms
Redis Deduplication Check: bill:sha256:{hash}
Checks if document has already been audited in Redis cache.
backend/app/services/cache/redis_client.py ➔ get_cached_bill()
🟢 Cache Hit (< 5ms):
Returns verified JSON immediately. UI displays notice: "Document already parsed and verified" and opens bill.
🟣 Cache Miss (< 10ms):
Writes Bill(file_data=bytes, status="PENDING") to PostgreSQL 17 BYTEA blob. Continues to Step 4.
⬇️
Step 4 < 1ms
Enqueue Bill ID & Return HTTP 202 Accepted
Pushes bill_id to in-memory asyncio.Queue. Returns HTTP 202 so the browser never times out.
backend/app/workers/queue.py ➔ task_queue.enqueue(bill_id)
⬇️
Step 5 ~2.2s
Poppler 200 DPI Rasterization & Tesseract 5 Neural OCR
Worker reads BYTEA from database. Poppler renders 200 DPI grayscale images; Tesseract extracts text tokens in one pass.
backend/app/services/ocr/engine.py ➔ DocumentOCREngine.extract()
⬇️
Step 6 < 5ms
Non-Bill Guardrail Classifier
Detects technical register maps (e.g. EM6400). Rejects with REJECTED_NON_BILL and sets clean null values.
backend/app/services/ocr/universal_extractor.py ➔ validate_is_electricity_bill()
⬇️
Step 7 < 15ms
Multi-DISCOM Regex Pattern Extraction
Extracts APDCL TOD registers (Solar, Peak, Normal), JVVNL Net Payable Amount preceding "Rupees Only", and GESCOM reference numbers.
backend/app/services/ocr/universal_extractor.py ➔ extract_heuristic_fields()
⬇️
Step 8 < 5ms
Deterministic Tariff Mathematical Audit
Verifies meter delta consistency ((Curr - Prev) * MF = Units), validates Power Factor bounds (0.0 to 1.0), and marks VERIFIED.
backend/app/services/verification/engine.py ➔ MathVerificationEngine.verify()
⬇️
Step 9 < 15ms
Realtime UI Render, In-Memory PDF View & CSV Export
Frontend unblurs, renders audited values, streams PDF binary from DB memory, and compiles the consolidated CSV export.
frontend/app/page.tsx + backend/app/api/v1/endpoints/bills.py ➔ export_all_bills_csv()
